# Stellar

Before building on Stellar, read https://skills.stellar.org and the topic matching the task:

| Task | Skill |
| --- | --- |
| Write, test, review, or deploy contracts | [Smart contracts](smart-contracts/SKILL.md) |
| Work with assets, trustlines, or SAC | [Assets](assets/SKILL.md) |
| Query chain data or orchestrate transactions | [Data](data/SKILL.md) |
| Check SEPs, CAPs, or ecosystem references | [Standards](standards/SKILL.md) |
| Evaluate cross-chain transfers or messaging | [Cross-chain](cross-chain/SKILL.md) |

Read each topic's relevant companion references. These topic folders come from https://github.com/stellar/stellar-dev-skill; this entry point groups them for project-local discovery.

Follow the root AGENTS.md rules, including the prohibition on code comments. Installing these references does not select dependencies or bridge providers. Verify current versions and network support before implementation.
